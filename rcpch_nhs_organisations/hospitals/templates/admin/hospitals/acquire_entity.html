{{ object }} acquires another {{ opts.verbose_name }}

This records a forward acquisition. In one transaction:

  1. Creates a succession row (type=acquisition) linking the acquired entity to this one.
  2. Closes the acquired entity's current version row and opens an inactive one.
  3. Marks the acquired entity active=False.
  4. Reassigns all of the acquired entity's child organisations to this entity.
    5. {% if opts.model_name == "paediatricdiabetesunit" %}
  5. Sets the lead_organisation FK on this PDU to the chosen lead organisation, so the /paediatric_diabetes_units/{pz_code}/parent/ endpoint reads the lead from the model.
  6. Updates the name source if it has changed (how this PDU's display name is derived — by lead organisation, parent trust, or parent local health board).
    7. {% else %}
  7. (Optional) Renames this entity, recording a separate rename succession row.
    8. {% endif %}
This cannot be undone. Verify the acquired entity, the effective date{% if opts.model_name == "paediatricdiabetesunit" %}, the name source, and the lead organisation{% endif %} before proceeding.
