Before creating a succession row by hand:

  • Recording a forward merger or acquisition? Use the Acquire another… or Merge into a new… wizard on the entity's change page instead. The wizard writes the succession row and the version rows and the child reassignments in one transaction, which this form does not do.
  • Recording a historical merger (backfill)? For trusts, use the Backfill merger… wizard on the Trust change page, which fetches the predecessor from ODS and writes the version rows. For PDUs (which are not in the ODS), create the row here and backfill the version rows separately.
  • Only create the row here directly for ambiguous cases the wizards cannot handle (e.g. a split where children move to different successors), or to correct a row the wizard created. ODS succession semantics are occasionally ambiguous and a human should confirm the predecessor → successor mapping.
